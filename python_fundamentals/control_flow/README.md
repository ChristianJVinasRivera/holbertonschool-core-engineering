# Python - Control Flow

Exercises on conditional statements, comparison operators, Boolean logic,
and loops in Python.

## Task 0: Positive or negative

`positive_or_negative.py` generates a random integer from -10 to 10 and
prints whether it is positive, zero, or negative using if, elif, and else.

Run the script:

```bash
./positive_or_negative.py
```

Check code style:

```bash
python3 -m pycodestyle positive_or_negative.py
```

## Task 1: The last digit

`last_digit.py` generates a random integer from -10000 to 10000 and
computes its last digit while preserving the sign. It prints whether
the digit is greater than 5, zero, or less than 6 and not zero.

Run the script:

```bash
./last_digit.py
```

Check code style:

```bash
python3 -m pycodestyle last_digit.py
```

## Task 2: Alphabet Game (Lowercase)

`print_alphabt.py` prints the lowercase alphabet except for `e` and `q`.
It uses one loop and one print call in the code, with string formatting.
The output has 24 characters, no spaces, and no trailing newline.

Run the script:

```bash
./print_alphabt.py
```

Check code style:

```bash
python3 -m pycodestyle print_alphabt.py
```

## Task 3: Hexadecimal Printing

`print_hexa.py` prints numbers from 0 to 98 in decimal and hexadecimal.
It uses one loop and one print call with string formatting.
Each line follows the format `98 = 0x62` and ends with a newline.

Run the script:

```bash
./print_hexa.py
```

Check code style:

```bash
python3 -m pycodestyle print_hexa.py
```
